# Seam Line

A fly-fishing forecast for rivers and streams: trout, steelhead, salmon and smallmouth.

- Fishability score by species, hourly outlook and best window
- Live USGS stream gauge flows and water temperature
- Weather from Open-Meteo, moon and solunar periods calculated on-device
- Fly box suggestions by month, water temperature and flow

Single-file app (`index.html`), served with GitHub Pages.
